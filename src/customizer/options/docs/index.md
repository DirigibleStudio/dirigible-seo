## Overview

**Options** has one site-wide control: **Title Separator**. That character is used whenever a title template includes a separator pill, and when Dirigible SEO builds a default title from the page name and the site name.

## Where to find these settings

1. In the WordPress admin, go to **Appearance → Customize**
2. Open **SEO**
3. Select the **Options** sub-panel

## Settings

- **Title Separator** — the character between the page name and the site name (default `-`)

## Tips

- Change this before you finish titles on a new site so every default title matches.
- The same character appears on the separator pill in the **SEO** sidebar on posts and pages.
